# Canteen-go

An efficient, user-friendly digital platform for ordering food, managing canteen pre-orders, and reducing wait times.

## 🚀 Features

- **Digital Menu:** Browse available food items and daily specials.
- **Pre-ordering:** Place orders in advance to skip long lunch queues.
- **Order Tracking:** Real-time updates on your order status (Pending, Preparing, Ready).
- **Admin Dashboard:** Canteen staff can update item availability and manage active orders.

## 🛠️ Tech Stack

- **Backend:** Go (Golang) / Node.js
- **Frontend:** React / HTML & CSS / Flutter
- **Database:** PostgreSQL / MongoDB
